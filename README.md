## What it does

`main.py` (pure Python standard library, no network, no input) writes one
line — under 200 characters — to `/output/entry.txt`: a sick-day excuse a
boss might half believe and a coworker would laugh at.

> Sorry, can't come in today — my car keys ended up in the freezer and my fridge is holding them hostage until I apologize.

Why this line: a believable everyday mishap (keys in the freezer) with the
laugh landing at the very end (the fridge holding them hostage). A fresh
idea — no fever, no dog, no dead grandmother — written the way a real
person would text their boss, with no wasted words.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
